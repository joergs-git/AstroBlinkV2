# Keyboard Shortcuts

## Navigation
| Key | Action |
|-----|--------|
| ← / → | Previous / Next image |
| Page Up / Home | Jump to first image |
| Page Down / End | Jump to last image |

## Triage
| Key | Action |
|-----|--------|
| Space | Toggle pre-delete mark (single or multi-selection) |
| Cmd+Backspace | Move marked files to _predel/ staging folder |
| Cmd+Z | Undo last pre-delete operation |
| K | Toggle skip marked images during navigation |
| H | Cycle: all files → hide marked → show only marked → all |

## Viewing
| Key | Action |
|-----|--------|
| S | Toggle stretch mode (auto / locked) |
| D | Toggle debayer for OSC images |
| N | Toggle night mode (red-on-black) |
| I | Toggle FITS/XISF header inspector |
| C | Compare current frame with group's best |
| + / - | Zoom in / out |
| 0 | Reset zoom to fit |
| Double-click | Reset zoom to fit / Open image preview |

## Session
| Key | Action |
|-----|--------|
| Cmd+O | Open folder |
| Cmd+M | Move marked files to a chosen folder |
| Cmd+Shift+R | Batch rename & header edit |
